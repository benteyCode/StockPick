# A 股实时条件筛选 — 设计规格

**日期：** 2026-05-20  
**项目：** StockPick（Android / Jetpack Compose）  
**状态：** 已定稿，待实现

---

## 1. 目标

在 A 股市场，用户**手动触发**一次筛选，基于固定技术规则从全市场（含创业板、科创板）中找出符合条件的个股，并在 App 内展示结果。

**核心场景：** 盘中实时盯盘辅助 — 用户点击「运行筛选」，App 拉取最新行情、计算指标、套用规则、展示命中列表。

**第一版不做：** 自定义规则编辑器、推送提醒、定时自动扫描、自选股子集、历史筛选记录、个股详情页、底部导航其他 Tab 的真实功能。

---

## 2. 筛选规则（R1–R4，AND 组合）

### R1：上升逻辑 + 回踩 MA10

| 子条件 | 定义 |
|--------|------|
| 均线多头 | MA10 > MA20 |
| 趋势未破 | 当前价（盘中用最新价）> MA20 |
| 确认回踩 | 近 5～10 个交易日内，至少 1 日收盘价 > MA10（当日 MA10） |
| 接近 MA10 | 当前价相对 MA10 偏差在 **[-1%, +1%]**（允许略破 MA10 下方 0～1%） |

偏差公式：`(price - MA10) / MA10`

### R2：均线粘合

`|MA10 - MA20| / MA20 ≤ 2%`

阈值第一版写死为 2%，后续可改为可配置参数。

### R3：前期放量

近 **20** 个交易日内，至少 **2** 天满足：`volume > 20日均量 × 1.5`

### R4：缩量阴线（盘中实时）

| 子条件 | 定义 |
|--------|------|
| 阴线 | 当前价 < 今日开盘价（盘中用最新价 vs 今开） |
| 缩量 | 当前成交量 < 近 5 日平均成交量（不含今日 partial 时可按已成交分钟比例估算，或直接用累计量 vs 5 日均量 — 实现时取累计量对比，文档注明盘中为近似） |

**盘中说明：** 未收盘时「今日」K 线为 partial candle，结果会随盘中变化；UI 必须展示「数据截至 HH:mm:ss」。

---

## 3. 筛选范围

- **包含：** 沪/深 A 股、创业板、科创板
- **排除：** ST / *ST、停牌、无成交
- **触发方式：** 用户手动点击「运行筛选」
- **数据时效：** 盘中实时（方案 A）

---

## 4. 技术方案

### 4.1 选定方案：App 直连 + 本地缓存 + 两阶段筛选（方案 3）

无自建后端。App 直接调用东方财富等免费公开接口，SQLite 缓存股票列表与 K 线，两阶段筛选降低请求量。

**不选纯客户端无缓存（方案 1）：** 全市场 ~5000 只，重复拉 K 线太慢。  
**不选后端代理（方案 2）：** 第一版 YAGNI，后续可迁移。

### 4.2 架构分层

```
UI 层 (Compose)
  └─ Editor 筛选页（唯一完整页面）
ViewModel / 用例层
  └─ RunScreenUseCase：编排筛选流程
领域层
  ├─ 规则引擎 ScreenRuleEngine（R1–R4 AND）
  └─ 指标计算 IndicatorCalculator（MA、均量）
数据层
  ├─ QuoteDataSource（东方财富等 HTTP 接口）
  └─ SQLite 缓存（股票列表、日 K 线）
```

### 4.3 数据流（一次手动筛选）

1. 用户点击「运行筛选」
2. 拉取/更新全 A 股列表（排除 ST、停牌）→ 缓存 1 天
3. **粗筛：** 批量拉全市场实时快照，廉价预过滤（如：有成交、价格在合理区间）
4. **精筛：** 对候选股拉近 30 日 K 线（优先读缓存，过期再拉）
5. 计算 MA10、MA20、5/20 日均量
6. 规则引擎逐条评估 R1–R4
7. 命中结果按「距 MA10 绝对值」升序排序
8. 更新 UI：上次运行时间、命中数量、数据截至时间、结果列表

### 4.4 数据源

- **类型：** 免费公开接口（东方财富为主，新浪等为备选）
- **需拉取：** 全市场股票列表、实时行情快照、个股日 K 线（≥30 日）
- **限频策略：** 批量请求、并发控制、失败重试（见 §6）

### 4.5 缓存策略

| 数据 | 有效期 | 刷新 |
|------|--------|------|
| 股票列表 | 1 天 | 手动刷新 / 跨日自动失效 |
| 日 K 线 | 当日有效 | 跨日失效；手动刷新强制拉新 |
| 筛选结果 | 不持久化 | 每次运行覆盖 |

## 5. UI 设计

### 5.1 整体风格

深色主题：深灰/黑底、蓝色主色（`StockPick` 标题、主按钮）、绿色强调（命中数、状态标签）。卡片圆角 + 细边框。

### 5.2 页面范围（第一版）

**仅实现 Editor（筛选页）。** 设计稿中的底部导航其他 Tab（Library / Stocks / Profile）及顶栏汉堡菜单第一版**隐藏或不做**；顶栏保留刷新按钮。

### 5.4 结果卡片字段

| 字段 | 来源 |
|------|------|
| 代码 + 名称 | 股票列表 |
| 交易所标签 | SH / SZ / 创业板 / 科创板 |
| 涨跌幅 | 实时行情（红跌绿涨） |
| 距 MA10 | R1 量化：`(price - MA10) / MA10` |
| 量比 | 今日累计量 / 5 日均量 |
| 状态标签 | 侧写标签，如 `MA10/20粘合`、`缩量回调` |

### 5.5 交互

| 场景 | 行为 |
|------|------|
| 点击「运行筛选」 | Loading + 进度：`拉取列表 → 粗筛 → 精筛 (128/500)` |
| 筛选进行中 | 可取消 |
| 顶栏刷新 | 强制拉新行情/K 线缓存，**不自动重跑规则** |
| 无结果 | 空态「当前无符合条件的股票」，命中 0 只 |
| 非交易时段 | 顶部提示「当前非交易时段，数据可能非实时」 |
| 点击结果卡片 | 第一版不跳转详情（无响应或 Toast「开发中」） |

## 6. 错误处理

| 场景 | 处理 |
|------|------|
| 网络失败 | Snackbar「网络异常，请检查连接」；保留上次结果与时间戳 |
| 限频/超时 | 自动重试最多 3 次（指数退避）；仍失败提示「部分数据拉取失败，请稍后重试」 |
| 股票列表拉取失败 | 阻断筛选，按钮恢复 |
| 单股 K 线失败 | 跳过，结束后提示「略过 N 只」 |
| 筛选取消 | 停止后续请求，清空进行中状态 |

### 7.2 Fixture 测试

固定 K 线数据集：至少 2 例应命中、2 例应排除。

### 7.3 集成测试

Mock `QuoteDataSource` → 完整 `RunScreenUseCase` → 断言结果数量与排序。

### 7.4 手动测试

- 交易时段全市场跑一次
- 非交易时段跑一次
- 断网 / 弱网
